# Personal Portfolio - ExpressJS & EJS

This is my personal portfolio website built with Node.js, Express, and EJS for Web & Script, Assignment 2.

## Live Links
- Live Site (Render): https://zafirsm.onrender.com
- GitHub Repo: https://github.com/Zafir-SM/Assignment2

## Pages Included
- Home (/): Intro overview, quick links, and my main focus areas (Networking, Security, Web Dev).
- About Me (/about): Short bio, profile photo, and intro video.
- Projects (/projects): Overview of my networking, Linux, database, and web dev coursework.
- Contact Me (/contact): Contact form and LinkedIn link.

## Folder Structure
- bin/www: Starts the server and sets the port.
- app.js: Sets up Express, EJS, and the static folders (public and node_modules).
- controllers/index.js: Handles the page routes and renders each EJS view.
- views/: Contains the 4 EJS pages and the shared partials folder (header, navbar, and footer).
- public/: Holds all custom CSS, images, and video files.
